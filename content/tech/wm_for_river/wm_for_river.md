## Writing my own Window Manager for RiverWM
There has been a new update for River. Following the versions from `0.4.x`, they have seperated the compositor with the window manager. It provides the users with either persoanlly made window managers or community made window managers. 

It uses `river-window-management-v1` protocol to communicate with the window management. I have been wanting to learn wayland protocol for a long time and I felt that it's the time that I learn wayland for my own take on window management.
