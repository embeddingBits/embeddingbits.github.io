Favourite

  • Operating System: I use Arch Linux.
  • Text/Code Editor: I use Neovim.
  • Window Manager: I use River.
  • Terminal and Shell: I use Ghostty combined with fish shell.
  • Dotfiles: I use my own dotfiles

Most of the softwares I use are made in Zig cause I love it so much :)

Utils

  • File Manager: I use Yazi as my main and only file manager.
  • Web Browser: I use Firefox and Qutebrowser all the time.
  • PDF Viewer: I use Zathura as my pdf viewer and firefox.
  • Misc: For most of the other stuff like Word, Excel, etc..., I use LibreOffice.

College

  • Reports and Documents: I use Typst and LaTeX.
  • Taking Notes: I manage my college and personal notes with Obsidian, Neorg and Typst.
