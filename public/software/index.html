Software that I use

Software that I use and you can love

November 4, 2025   ·  1 min read  ·  106 words

#Linux #Window Manager #Terminal #Text Editor #Utilities #Notes #Documentation

Favourite

  • Operating System: I use Arch Linux.
  • Text/Code Editor: I use Emacs and Neovim.
  • Window Manager: I use River.
  • Terminal and Shell: I use Foot combined with fish shell.
  • Dotfiles: I use my own dotfiles.

Utils

  • File Manager: I use Yazi as my main and only file manager.
  • Web Browser: I use Firefox
  • PDF Viewer: I use Zathura and pdf-tools in Emacs.
  • Misc: For most of the other stuff like Word, Excel, etc., I use LibreOffice.

College

  • Reports and Documents: I use Typst and I write in Org Mode and export it to LaTeX.
  • Taking Notes: I manage my college and personal notes with Org Mode.
